# Aula 020 — Contrato de monitoramento (fecho)

Fecha a trilha: redija **uma página** que amarra os três fins da
[`000`](../000_mlops_pipelines_goals/README.md) — saúde do servidor, drift de
dados, detecção de anomalias — a sinais, limiares, dono e acção.

Não há serviço novo. Use o modelo
[`CONTRACT_TEMPLATE.md`](CONTRACT_TEMPLATE.md).

## Objectivos

1. Escolher, para cada fim, um sinal já visto na trilha (métrica, painel ou
   estatística de alerta).
2. Declarar limiar e o que acontece se for violado.
3. Citar pastas concretas (`010`/`016`, `003`/`008`, `004`, …).

## Entrega

Cópia preenchida do modelo (Markdown). Rubrica mínima:

| Critério | Aceitável |
| :--- | :--- |
| Três fins cobertos | Uma linha de sinal por fim |
| Rastreio | Cada sinal aponta a uma aula `NNN_*` |
| Acção | Há dono ou papel responsável nomeado |
| Honestidade | Se um lab opcional ficou de fora (ex.: Datadog sem chave), diga «não disponível» — não invente cobertura |
