## Recommended Approach

Approach B — show-ready independent lesson. Rationale: ships the dark-magic
live show with a same-theme control so the turma can still see when the alert
stays quiet; stays independent of `040`; matches SAMPLE quality; parks 10x work.

Working folder name (open to tweak): `003_ks_drift_alert_streamlit` (exact slug
at implement time). Current `003_prometheus_histcdf_streamlit` → `004_…`.

**Tree layout (eng-review):** flat lesson directory at the SAMPLE root (same
shape as `020`/`040`) — not a `service/`+`app/` split.

### v1 committed behavior (locks from spec review)

- **Feature unit:** luminance (L) channel **histogram → CDF**, same family as
  `001`/`002`/`040`. Not one scalar per image in v1.
- **Corpus path:** ship a **precomputed** corpus stats artifact for theme A
  (beaches by default) in the lesson tree for the live show / expected numbers;
  also ship `just build-corpus-stats` so students can rebuild. Demo and handout
  expected outcomes use the shipped freeze.
- **KS / alert rule (classroom):** compare reference CDF to the selected
  production batch CDF. Display **D**, **p-value**, and a three-state banner:
  - **ALERT** if `p < 0.05` and `D ≥ 0.10`
  - **WATCH** if exactly one of those two fires
  - **QUIET** if neither fires
  - **INCONCLUSIVE** (overrides the three above) if either side has
    `n_images < 8` (small-n; show counts and refuse to claim ALERT)
- **n_eff:** effective sample size used in the asymptotic KS p-value, derived
  from **image counts** on each side (same spirit as `040`). Shown in Streamlit
  next to D/p and glossed once in the handout.
- **Control batch:** same-theme holdout expected to land QUIET or WATCH under
  the shipped freeze; if a run is INCONCLUSIVE, handout says re-run / check
  counts — not “control always silent.”
- **Service surface:** BentoML = inference + request logging only; KS lives in
  Streamlit (no `/monitor-ks-*` in this lesson).

## Contingency (verify-before-lock handout)

If beaches-vs-forests KS is **not distinct enough** under the v1 alert rule
(shipped freeze fails to show ALERT on the drift batch), fall back to:

- **Corpus / “treino”:** merge both landscape themes (`beaches/` + `forests/`)
- **Divergent production:** `balls/`

Re-verify D/p and the banner before locking expected handout numbers. Prefer
this over weakening the classroom thresholds.

**Implemented verify (2026-10-26):** beaches[:12] corpus vs forests → **WATCH**
(D≈0.33, p≈0.43 with image-count n_eff); vs control beaches[12:] → **QUIET**.
Handout locks those banners (D carries the show). balls (n=6) → INCONCLUSIVE
until ≥8 images; landscapes→balls same issue on n_p.

## Success Criteria

- Student can: use shipped theme-A corpus (or rebuild via `just`); send theme B
  and same-theme control through logged grayscale; open Streamlit; see L CDFs,
  D, p-value, n_eff, thumbnails, and the ALERT/WATCH/QUIET/INCONCLUSIVE banner;
  see ALERT on the drift batch under the shipped freeze (verify once before
  locking handout numbers); see control land QUIET or WATCH (or INCONCLUSIVE
  only if counts are short).
- Lesson tree is runnable alone (`uv`/`just`); tests cover KS math + log shape
  + banner rule.
- `000` index and `002` next-link point at the new `003`; Prometheus lives at `004`.
- Handout stands alone (SAMPLE-006 sections); no “see `040`” narrative.
